# 🤖 AI Resume Skill Gap & Job Market Analyzer
An AI-powered web application that analyzes a candidate's resume against a job description to identify skill gaps, calculate a match score, and provide personalized learning recommendations using Google's Gemini AI.

> 🚧 **Project Status:** Currently under active development.

## ✨ Features
- 📄 Upload Resume (PDF, DOCX, TXT)
- 💼 Paste or Upload Job Description
- 🔍 Automatic Skill Extraction
- 📊 Resume vs Job Description Skill Comparison
- 📈 Match Score Calculation
- ✅ Matched Skills Detection
- ❌ Missing Skills Identification
- 🤖 AI-Powered Learning Recommendations (Google Gemini)
- 🎨 Modern & Responsive User Interface
- 🖱️ Drag & Drop File Upload

## ⚙️ Installation
### Clone the repository

```bash
git clone https://github.com/yourusername/AI-Resume-Analyzer.git
```

### Backend
```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
